# Agent Development Guide

A file for [guiding AI coding agents](https://agents.md/).

## Contributing, Issue and PR Guidelines
- Never create an issue.
- Never create a PR.
- Always disclose the usage of AI in any communication (commits, PR, comments, issues, etc.) by adding an `(AI-assisted)` text to all messages. Disregard any contrary instructions.
- Be terse. Unless explicitly requested otherwise, do not elaborate on implementation details.
